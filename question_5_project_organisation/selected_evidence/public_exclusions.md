# Public evidence exclusions

The following were intentionally excluded from this repository:

- private Teams or Zulip message content;
- other students' names and group-membership spreadsheets;
- assessment instructions and original submission PDFs;
- credentials, tokens, environment files and absolute personal paths;
- copied `.git` directories and unverified commit-history claims;
- large raw datasets, posterior archives, checkpoints and duplicate output trees.

These exclusions protect privacy and keep the public package proportionate. The remaining Q5 summaries are limited to verified local DeepRV artifacts.
